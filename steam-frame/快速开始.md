# Clash Verge Rev × Steam Frame 测试包

把 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) 装到 **Valve Steam Frame**
（骁龙 8 Gen 3 / ARM64 / SteamOS）上的一套工具。已在真机（SteamOS `VARIANT_ID=vr`）上跑通全流程。

---

## 包里有什么

| 文件 | 大小 | 作用 |
|---|---|---|
| `ClashVergeFrameManager.exe` | 90 KB | **图形界面管理器，主要就是这个**。双击运行 |
| `cvframe-cli.exe` | 90 KB | 命令行版，同一套逻辑，排查问题用 |
| `install-clash-verge-frame.run` | 120 MB | 离线安装包，自带全部依赖。GUI 的「一键部署安装」用它 |
| `install-clash-verge-frame.sh` | 19 KB | 联网版安装器（不需要那个 120 MB 时用） |
| `steam-shortcuts.py` | 9 KB | Steam 非 Steam 库助手（清理重复条目用；功能已内嵌进 exe） |
| `uninstall-clash-verge-frame.sh` | 13 KB | 设备端完整卸载脚本（功能已内嵌进 exe，单独文件供手动排查） |
| `README-zh.md` | 28 KB | 完整技术文档（含 SteamOS 差异实测、原理、已知限制） |

> `README-zh.md` 是完整的开发文档，里面「文件清单」一节列的是**全部产物**（含源码、
> CI 配置、早期版本的控制台部署器）。本测试包只含上表这几个运行必需的文件。
> 包里另有 `push-subscription.py`（设备侧的订阅导入助手，功能已内嵌进 exe，
> 单独文件仅供手动排查用）和 `SHA256SUMS.txt`（校验和）。

**为什么安装包要 120 MB？** 因为 Steam Frame 上唯一缺的运行时依赖是 `webkit2gtk-4.1`，
而 WebKit 的辅助进程路径是编译期硬编码的、**无法随应用打包**，只能由系统提供。
这个包里直接内嵌了 Valve 官方仓库的 webkit2gtk-4.1 及其依赖，所以能在**完全不联网**的情况下装好。
里面是已压缩过的 deb / zst，再压也压不动，所以 zip 体积基本就是这个数。

## 开始之前

* **一台 Windows 电脑**，需要系统自带的 OpenSSH 客户端。
  检查：命令行执行 `ssh -V`，有版本号输出就行。
  没有的话：设置 → 系统 → 可选功能 → 添加功能 → 安装「OpenSSH 客户端」。
* **一台 Steam Frame**，并且知道它的 IP，以及 `steamos` 用户的密码。
  （框架机默认用户名是 `steamos`。）
* 建议先确认能手动 SSH 上去：
  ```bat
  ssh steamos@<你的Frame的IP>
  ```

> **注意：这个 exe 没有代码签名。** 从网上传过来的文件，Windows SmartScreen 可能拦截
> （「Windows 已保护你的电脑」）。点「更多信息」→「仍要运行」即可。
> 不放心的话可以核对 `SHA256SUMS.txt` 里的哈希。

## 三步走

### 第 1 步：连接

打开 `ClashVergeFrameManager.exe`，在「**1. 设备连接**」里填：

* **主机 / SSH 别名**：Frame 的 IP，例如 `192.168.1.129`
* **用户名**：`steamos`
* **密码**：你的密码
* 勾上「记住密码」（DPAPI 加密保存，只有当前 Windows 用户能解密；不想存就取消勾选）

点「**测试连接**」。看到类似下面的输出就算通了：

```
aarch64
SteamOS variant=vr
webkit2gtk-4.1 2.44.1-1    ← 如果是 MISSING，第 2 步会自动装上
clash-verge NOT-INSTALLED
app STOPPED / core STOPPED
```

**这一步程序会自动生成一对 SSH 密钥并装到 Frame 上**，之后就不用再输密码了。
如果以后 Frame 重装了系统，`authorized_keys` 被清空，程序会用你保存的密码**自动重建密钥**，
不用手动处理。

> 你也可以完全不填用户名密码，改成在自己电脑的 `%USERPROFILE%\.ssh\config` 里配好
> `Host frame` 那种免密登录，然后主机栏直接填 `frame`。程序两种都支持。

### 第 2 步：安装

「**2. 安装 / 更新**」里确认安装包路径指向 `install-clash-verge-frame.run`（会自动找到），
点「**一键部署安装**」。

**正常情况下你什么都不用输。** 远程安装需要一次 `sudo` 权限（装 webkit2gtk-4.1），
程序会**直接把第 1 步填的 SSH 密码当成 sudo 密码喂过去** —— 两者通常本来就是同一个。

只有当这个密码被 sudo 拒绝时，才会弹出一个**单独的小窗口**问你要密码：

* 窗口里**输入内容是明文显示的**（不遮成圆点），方便边看边核对，避免盲打输错
* 输完回车，密码回传给程序，接着继续安装

程序装在 `~/.local/opt/clash-verge`，**不碰只读的系统分区**，所以系统更新后应用本体还在。

> 卸载走的是**完全相同**的一套 sudo 逻辑。

### 第 3 步：导入订阅

「**4. 订阅推送**」里填订阅链接（名称可留空），点「**推送订阅**」。
程序会在**你的电脑上**先下载订阅（用你电脑的代理，这一步很关键 ——
Frame 此时还没有任何代理，自己拉机场链接容易失败），然后推到 Frame 并写入配置。

推完 Frame 上的 Clash Verge 会自动重启并启用这个订阅。
想确认的话点「读取设备上的订阅」，应该能看到刚推的那个。

## 让 SteamVR 里的 Steam 也走代理

「系统代理」只管桌面模式。**游戏模式 / SteamVR 里的 Steam 要走代理，必须用 TUN 模式**。

1. 在**头显里**打开 Clash Verge
2. 打开「**TUN 模式**」开关
3. 它会弹出权限请求 —— 这时**切到桌面模式，输入系统密码**（这一步会装一个官方系统服务）
4. 装好一次以后就不用再输了

之后 SteamVR 里的 Steam 社区就能打开了。

## 不想用了：一键卸载

「**2. 安装 / 更新**」里的「**一键卸载**」按钮，点开会弹一个确认框，然后完整清理：

* 程序与启动器
* **Steam「非 Steam 游戏库」里的条目**
* **桌面菜单项与图标**
* 官方系统服务 `clash-verge-service`（需要 sudo）

确认框里有两个**默认不勾选**的选项：

| 选项 | 默认 | 勾上会怎样 |
|---|---|---|
| 同时删除配置、订阅与日志 | 不勾 | 订阅链接需要重新填 |
| 同时卸载系统依赖 webkit2gtk-4.1 | 不勾 | 少占约 100 MB，但如无其他程序在用 |

> **卸载会先退出 Steam。** 这是必须的：Steam 只在退出时才把快捷方式配置写回磁盘，
> 它运行期间做的改动会被覆盖，库里的条目删不掉。

想先看会做什么、不改动任何东西：

```bat
cvframe-cli.exe --cli --host frame --uninstall --dry-run
```

## 遇到问题

**「测试连接」失败**
先手动 `ssh steamos@<IP>` 试一次。程序是用 SSH 工作的，手动都连不上，程序也连不上。

**「一键部署安装」失败**
日志区会显示完整输出。最常见的是 sudo 密码不对 —— 程序会自动弹窗让你重输。
如果提示连不上，先在命令行手动 `ssh steamos@<IP>` 试一次。

**订阅推上去了但没网**
确认订阅本身是好的：点「在本机测试下载」，看返回的是不是 Clash 配置
（应该含 `proxies:` 或 `proxy-providers:`）。如果返回的是网页 HTML，说明订阅链接或 User-Agent 不对。

**设备重装系统之后**
重跑一次「一键部署安装」即可，安装器是幂等的。密钥会用保存的密码自动重建。

**Steam 库里出现多个同名的 Clash Verge**
`steamos-add-to-steam` 每次调用都会新增一条，不会去重。可以在设备上执行：
```bash
python3 ~/steam-shortcuts.py --list       # 先看看
python3 ~/steam-shortcuts.py --dedupe     # 保留一个，去掉重复
```
改之前会备份成 `shortcuts.vdf.bak`。改的时候 Steam 必须没在运行。

## 关于安全

* **密码**用 Windows DPAPI（`CurrentUser` 作用域）加密存放，磁盘上不是明文，只有当前 Windows 用户能解密
* 传给 ssh 时走**环境变量**，不落盘、不进命令行（其它进程看不到）
* 需要 sudo 时，密码通过设备上一个 `600` 权限的临时文件传递（不放进命令行，否则会出现在设备的 `ps` 里），
  **远端脚本读完立刻删除**，程序侧也不落盘
* 程序用的是**独立的** known_hosts 与 SSH 配置，**不会动你 `%USERPROFILE%\.ssh\` 下的任何东西**
* 程序会在自己的数据目录（首次运行时界面日志里会显示具体路径，点「打开密钥目录」可直接打开）
  生成一对专用密钥
* 安装包从上游官方 Release 与 Valve 官方仓库取，`:~/.local` 下安装，不需要关闭根文件系统只读保护
